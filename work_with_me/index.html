HOW I WORK

No empezamos con una herramienta. Empezamos entendiendo el problema.

Cada proyecto comienza entendiendo qué se quiere resolver, qué información existe y qué decisión necesita ser tomada. La tecnología aparece después, como una herramienta para construir la solución adecuada.

01

Entender

Entendemos el problema, los objetivos, el contexto y las decisiones que necesitan ser tomadas.

02

Estructurar

Organizamos datos, procesos y variables para construir una base confiable sobre la cual trabajar.

03

Analizar

Identificamos patrones, relaciones, métricas, escenarios y oportunidades que ayuden a entender el problema.

04

Construir

Convertimos los hallazgos en una solución que pueda utilizarse para apoyar decisiones y generar resultados.

Problema → Datos → Análisis → Solución → Decisión
